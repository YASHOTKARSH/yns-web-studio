# YNS Web Studio

Professional websites for coaching institutes and local businesses.

## About

YNS Web Studio creates simple, clean, and enquiry-focused websites for:
- Coaching institutes
- Local businesses
- Service providers

## Features

- ✅ Mobile-first responsive design
- ✅ Fast loading times
- ✅ SEO-ready structure
- ✅ Clean, professional layout
- ✅ Clear call-to-actions
- ✅ No unnecessary animations or features

## Tech Stack

- Pure HTML5
- CSS3 with mobile-first approach
- Static site (no backend required)
- Hosted on Netlify

## Deployment

This is a static website optimized for Netlify deployment:

1. Connect your GitHub repository to Netlify
2. Netlify will automatically deploy from the `netlify.toml` configuration
3. No build step required
