A clean, modern, single-page website for YNS Web Studio - helping coaching institutes and local businesses build professional online presence.

- **Professional Design**: Clean, trust-focused design with green color scheme (#28a745)
- **Mobile-First**: Fully responsive design optimized for all devices
- **Fast Loading**: Static HTML/CSS with no heavy animations or scripts

- **Contact Ready**: Direct call and WhatsApp integration

## 🚀 Deployment

This website is configured for deployment on Netlify:

1. Push the repository to GitHub
2. Connect to Netlify
3. Deploy from the main branch
4. The website will be live automatically

The `netlify.toml` file includes:
- Security headers (X-Frame-Options, X-XSS-Protection, etc.)
- Optimized caching for static assets
- Single-page app redirects

## 🛠️ Local Development

To run locally:

```bash
# Using Python
python3 -m http.server 8080

# Or using Node.js
npx serve
```

Then open `http://localhost:8080` in your browser.
